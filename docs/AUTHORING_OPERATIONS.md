# Authoring Operations

YCD builders accept an optional `AuthoringOperation` for progress and cooperative
cancellation. The same contract is independent of the format and can be used by
other authoring APIs as they adopt operation support.

```python
from fivefury import (
    AuthoringOperation,
    AuthoringProgress,
    YcdCutsceneBuilder,
)

def receive_progress(progress: AuthoringProgress) -> None:
    print(progress.stage, progress.asset, progress.completed, progress.total)

operation = AuthoringOperation(progress=receive_progress)
builder = YcdCutsceneBuilder.create("scene", duration=5.0)
builder.prop("actor")
assets = builder.build_ycds(operation=operation)
```

`build_section`, `build_ycds`, `validate` and `save` accept `operation=`.
The operation is optional and does not change precision policy or generated bytes.

## Threading And Cancellation

- Callbacks execute synchronously on the authoring thread. Dispatch to your UI's
  event queue rather than updating UI objects directly from the callback.
- Another thread can call `operation.cancel()`. The next checkpoint raises
  `AuthoringCancelled`; a cancelled operation cannot be reused.
- Validation checks cancellation between sequence blocks. Encoding and resource
  serialization complete their current unit of work before reaching a checkpoint.
- Saving validates every section before writing final files. Each replacement is
  atomic, but a multi-file save is not a transaction: cancellation during writing
  may leave already completed files in place.
- Callbacks and cancellation never bypass validation or change tolerances.

## Progress Units

`AuthoringProgress` contains a typed `AuthoringStage`, an asset name, a completed
count and a total count. Counts belong to that stage and asset, not a global
percentage: building reports sections, validation reports constrained tracks in
one YCD, and writing reports output files.

## Precision And Mutation

Validation reads the serialized resource back before comparing samples. Native
comparison interpolates stored channels before reconstructing or normalizing
cached quaternions. Integer errors and fractional angular errors retain separate
diagnostics; fractional checks include sequence overlaps.

Build reuse is scoped to one call. Editing tracks and building again constructs
and validates new assets. No precision result or serialized output is cached on
the mutable builder for later calls.
